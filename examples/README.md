# 各章の完成例

各ディレクトリには、対応する章を最後まで進めた状態のコードを置いています。自分のコードと比較したり、動作を確認したりするために使います。

教材を進めるときは、リポジトリ直下の `src/` を編集します。完成例は `examples/` の中にあります。

## 完成例を起動する

ターミナルの作業場所を、`package.json` があるリポジトリ直下にします。パッケージのインストールは、ここで一度行います。

```sh
npm install
```

通常のアプリを起動中なら、ターミナルで `Ctrl + C` を押して停止します。次に、見たい章のディレクトリを指定して起動します。

```sh
npm run dev:example -- examples/03-css-and-images
```

`--` より後ろのディレクトリ名を変更すると、別の完成例を開けます。ターミナルに表示された URL をブラウザで開いてください。

| 章 | 完成例 | 確認できること |
| --- | --- | --- |
| 00 | [起動と道具](00-getting-started/) | 見出しの変更 |
| 01 | [JSX](01-jsx/) | 文字を直接書いた紹介画面 |
| 02 | [ローカル JSON](02-local-json/) | JSON から読み込んだ1匹の情報 |
| 03 | [CSS と画像](03-css-and-images/) | 画像付きの図鑑カード |
| 04 | [コンポーネント](04-components/) | props で渡した1匹のカード |
| 05 | [一覧](05-list/) | 全件のカードと複数タイプ |
| 06 | [クリックと state](06-state/) | 選択した番号とボタンの状態 |
| 07 | [詳細画面](07-detail/) | 一覧・詳細の切り替えとステータス |
| 08 | [名前検索](08-search/) | 入力に合わせた検索結果 |
| 09 | [タイプ絞り込み](09-type-filter/) | 名前とタイプの複合条件 |
| 10 | [並び替え](10-sort/) | 図鑑番号の昇順・降順 |
| 11 | [条件操作のモーダル](11-filter-modal/) | 条件画面の開閉とキーボード操作 |
| 12 | [PokéAPI](12-pokeapi/) | API の取得、エラーと再試行、キャッシュ |
| 13 | [仕上げ](13-finish/) | 条件リセット、フォーカス復帰、画面幅への対応 |

第03章以降の画像と、第12章以降のデータは外部 URL から読み込みます。インターネット接続が必要です。第12章以降はポケモン名が英語表示になり、名前検索も英語名を使います。

完成例を閉じた後に学習用アプリへ戻るには、`Ctrl + C` で停止してから `npm run dev` を実行します。

## 完成例をビルドする

```sh
npm run build:example -- examples/03-css-and-images
```

指定した完成例のディレクトリに `dist/` が生成されます。起動とビルドには、リポジトリ直下のパッケージと Vite 設定を使用します。

ビルドした完成例を確認するには、同じディレクトリを指定してプレビューします。

```sh
npm run preview -- examples/03-css-and-images
```
