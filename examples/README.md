# 各章の完成例

各ディレクトリには、対応する章を最後まで進めた状態のコードを置いています。自分のコードと比較したり、動作を確認したりするために使います。

教材を進めるときは、リポジトリ直下の `src/` を編集します。完成例は `examples/` の中にあります。

## 完成例を起動する

ターミナルの作業場所を、`package.json` があるリポジトリ直下にします。パッケージのインストールは、ここで一度行います。

```sh
npm install
```

通常のアプリを起動中なら、ターミナルで `Ctrl + C` を押して停止します。次に、見たい章のディレクトリを指定して起動します。

```sh
npm run dev:example -- examples/03-css-and-images
```

`--` より後ろのディレクトリ名を変更すると、別の完成例を開けます。ターミナルに表示された URL をブラウザで開いてください。

第18章以降のお気に入りと、第19章以降のテーマは localStorage に保存します。同じオリジン（プロトコル・ホスト・ポート）が一致する完成例では保存値を共有します。別の章を開いても、前に選んだ値が復元される場合があります。

第24章以降はアドレス欄の条件から表示を復元します。第25章では、例えば起動したURLに `?pokemon=6` を付けると番号6の詳細を直接開けます。

完成例を閉じた後に学習用アプリへ戻るには、`Ctrl + C` で停止してから `npm run dev` を実行します。

## 完成例をビルドする

```sh
npm run build:example -- examples/03-css-and-images
```

指定した完成例のディレクトリに `dist/` が生成されます。起動とビルドには、リポジトリ直下のパッケージと Vite 設定を使用します。

ビルドした完成例を確認するには、同じディレクトリを指定してプレビューします。

```sh
npm run preview -- examples/03-css-and-images
```
