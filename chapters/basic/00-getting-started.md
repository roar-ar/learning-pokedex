# 第00章 起動と道具

この章では、アプリを起動し、画面に表示する文字を変更します。エラーが出たときに、問題のあるファイルを見つけて直す練習もします。

## この章の目標

- 開発サーバーを起動・停止できる
- `src/App.jsx` の変更をブラウザで確認できる
- エラーの場所を調べ、動く状態に戻せる

コードはリポジトリ直下の `src/` に書きます。この章の完成例は [examples/00-getting-started/](../../examples/00-getting-started/) にあります。

## ステップ1 作業するフォルダーを確認する

ターミナルは、文字でコマンドを入力してプログラムを実行する道具です。コマンドは、現在開いているフォルダーを作業場所として実行されます。

リポジトリのフォルダーをエディターで開き、そのフォルダーを作業場所にしたターミナルを開いてください。`package.json` と `src/` が見える場所で作業します。

親フォルダーでターミナルを開いた場合は、次のコマンドでリポジトリへ移動できます。`cd` は作業場所を変えるコマンドです。取得したフォルダーの名前が異なる場合は、その名前に読み替えます。

```sh
cd learning-pokedex
```

これから使うファイルの役割を確認します。

| ファイル・フォルダー | 役割 |
| --- | --- |
| `package.json` | 使用するパッケージと起動コマンドの設定 |
| `index.html` | ブラウザが読み込むページの入口 |
| `src/main.jsx` | React の画面をページへ表示する処理 |
| `src/App.jsx` | 自分で編集する画面 |
| `src/styles.css` | 文字や余白などの共通スタイル |
| `chapters/` | 教材 |
| `examples/` | 各章の完成例 |

次のコマンドを1行ずつ実行します。

```sh
node --version
npm --version
```

**確認：** 両方ともバージョン番号が表示されれば準備できています。Node.js は 20.19 以上、または 22.12 以上の対応バージョンを使ってください。Vite の必要条件は [Vite 公式ガイド](https://vite.dev/guide/) に記載されています。Node.js が入っていない場合は [公式ダウンロードページ](https://nodejs.org/ja/download) からインストールし、ターミナルを開き直します。


## ステップ2 必要なパッケージをインストールする

React や Vite は、このアプリが使うパッケージです。npm は、`package.json` に記載されたパッケージをインストールするためにも使います。

リポジトリ直下で実行します。

```sh
npm install
```

**確認：** コマンドが終了し、再び入力できる状態になることを確認します。インストールされたパッケージは `node_modules/` に置かれます。

`package.json` が見つからないというエラーが出た場合は、ターミナルの作業場所を確認してください。インストールにはインターネット接続が必要です。

## ステップ3 アプリを起動する

開発サーバーは、編集中のアプリをブラウザで確認するためのプログラムです。このリポジトリでは Vite を使います。[Vite 公式ガイド](https://vite.dev/guide/)

```sh
npm run dev
```

ターミナルに表示された URL をブラウザで開きます。通常は `http://localhost:5173/` ですが、使用中のポートがあると別の番号になることがあります。表示された URL を使ってください。

**確認：** ブラウザに `Hello World` が表示されます。サーバーを動かしているターミナルは、そのまま開いておきます。

`index.html` のファイルを直接開くのではなく、開発サーバーの URL を開くことで、React のコードを動かせます。

## ステップ4 画面の文字を変更する

`src/App.jsx` を開きます。最初は次のコードがあります。

```jsx
export default function App() {
  return <h1>Hello World</h1>
}
```

`Hello World` を `はじめてのReact` に変更して保存します。

```jsx
export default function App() {
  return <h1>はじめてのReact</h1>
}
```

`<h1>` と `</h1>` の間にある文字が、画面の見出しになります。ほかの記号の意味は次の章で確かめます。

**確認：** ブラウザの見出しが変わります。通常は保存すると表示も更新されます。変わらない場合は、ファイルを保存したか、開発サーバーの URL を開いているかを確認します。

## ステップ5 ブラウザの開発者ツールを開く

開発者ツールを使うと、画面の要素やエラーを調べられます。Chrome または Edge では、見出しを右クリックして「検証」を選ぶと開けます。[Chrome DevTools の開き方](https://developer.chrome.com/docs/devtools/open?hl=ja)

次の2か所を開いてみてください。表示名はブラウザの言語設定によって異なります。

- **Elements／要素：** ページを構成している HTML を確認する場所
- **Console／コンソール：** JavaScript のエラーなどを確認する場所

**確認：** 要素の画面で `h1` を見つけ、その中に `はじめてのReact` があることを確認します。コンソールにも切り替え、アプリに関する赤いエラーが出ていないか見てください。

## ステップ6 エラーを出してから直す

コードの記号が合っていないと、表示を作れないことがあります。エラーを調べる練習として、`src/App.jsx` の閉じるタグを一時的に変更します。

次は、練習用の誤ったコードです。

```jsx
export default function App() {
  return <h1>はじめてのReact</h2>
}
```

保存してブラウザとターミナルを見ます。

**確認：** エラーが表示され、`App.jsx` や該当する行の情報があることを確認してください。文面は環境によって異なりますが、まずファイル名とコードの位置を探します。

原因は、開くタグが `h1`、閉じるタグが `h2` になっていることです。`</h2>` を `</h1>` に直し、保存します。

**確認：** 見出しが再び表示されます。コンソールやターミナルには過去のエラーが残ることがあります。修正後の保存・再読み込みで、新しいエラーが出ていないことを確かめましょう。

## ステップ7 開発サーバーを停止して再開する

開発サーバーを動かしているターミナルで `Ctrl + C` を押します。停止の確認が出た場合は、画面の案内に従います。

**確認：** ターミナルが再びコマンドを入力できる状態になります。すでに開いたページは表示が残ることがありますが、サーバーを止めた後は変更を受け取れません。

もう一度起動します。

```sh
npm run dev
```

**確認：** 表示された URL で `はじめてのReact` を開けます。

## 小さな練習

見出しを好きな文章に変えて、保存による更新を確認してください。確認後は `はじめてのReact` に戻し、次の章へ進みます。
