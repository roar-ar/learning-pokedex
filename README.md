# React で作るポケモン図鑑

ポケモン図鑑を少しずつ作りながら React の基本を身につけるためのリポジトリです。

JavaScript と JSX で React を記述し、アプリケーションフレームワークは使いません。
Vite は開発サーバーとビルドに使用します。

## 作るもの

1つの画面で一覧と詳細を切り替えるポケモン図鑑を作ります。完成時には、次の操作ができます。

- 図鑑番号・名前・画像を一覧で見る
- ポケモンを選び、タイプ・特性・高さ・重さ・ステータスを詳しく見る
- 名前検索、タイプでの絞り込み、図鑑番号での並び替えを行う
- 検索や並び替えの条件をモーダルから操作する
- API からデータを読み込み、通信中やエラー時の表示を切り替える

現在のアプリは `Hello World` から始まります。
章を進めるごとに機能を追加します。

## 学ぶこと

- HTML・CSS・JavaScript の基本と、ブラウザの開発者ツールの使い方
- JSX、コンポーネント、props による画面の組み立て
- イベント、state、条件付き表示による画面の更新
- 配列の `map`・`filter`・`sort` を使った一覧の表示と操作
- `fetch` と `useEffect` を使った API 通信、読み込み中・エラーの扱い
- 入力欄やボタンのラベル、キーボード操作などの基本的な使いやすさ

## 学習目標

必修チャプターを終えたら、次のことを自分の言葉で説明し、実装できる状態を目指します。

1. データから画面が作られ、操作によって表示が更新される流れを説明する。
2. コンポーネントを分け、props と state を使って値や操作を受け渡す。
3. 一覧の検索・絞り込み・並び替えを追加または変更する。
4. API の応答を確認し、読み込みやエラーに応じた表示を作る。
5. 開発者ツールで問題を調べ、ビルドで完成したアプリを確認する。

## 始め方

Node.js 20.19 以上、または 22.12 以上と npm を用意してください。

```sh
npm install
npm run dev
```

ターミナルに表示される URL をブラウザで開きます。
最初は `Hello World` が表示されます。

## 必修チャプター

第00章から順番に進めます。

各ステップで説明を読み、コードを変更して、ブラウザで結果を確認します。自分のコードはリポジトリ直下の `src/` に書いてください。第00〜13章の本文と完成例を用意しています。

完成例の起動方法は [examples の案内](examples/README.md) を参照してください。

### 教材の読み方

コードを編集できるエディター、ターミナル、ブラウザを使います。HTML・CSS・JavaScript の記法は、各章で使うものから説明します。

- 「全体を置き換える」とある場合は、そのファイル全体を書き換えます。それ以外のコードは、指定した場所へ追加・変更するための抜粋です。
- 各ステップの「確認」ができてから、次へ進みます。一時的な変更を試す練習は、案内に従って元に戻します。
- 動かなくなったら、コンソールの最初のエラーと、直前に変更したファイルを確認します。完成例と比べるときは、対応する章の同じファイルを開きます。

## 主なディレクトリとファイル

| パス | 役割 |
| --- | --- |
| `chapters/` | 順番に読む教材 |
| `examples/` | 各章を終えた状態の完成例 |
